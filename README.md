# Xsee · 星雨图片查看器

一款 Windows 看图软件。界面布局照 ACDSee 3.0 那一套重排了一遍——作者用它很多年，熟那一套手感。在看图之外加了三样：图片管理（按类别把图归起来）、以图搜图（找长得像的图）、参考图画布（把图浮在别的软件上当对照）。

里面有哪些功能、支持哪些文件格式，都是按作者自己日常要用到的那些定的，这不是一个长期开发的项目：现在这份就是最终版。想要更多功能、要额外的文件格式支持，或者碰到了 bug，都不必提 issue——源码在这里，自己下回去改就行。

窗口全部自己画：标题栏、菜单、弹层、缩略图格子、对话框都不依赖任何 UI 框架，配色、版式、图标可以整套换掉。

## 能做什么

- **浏览**：文件夹树 + 缩略图 / 图标 / 列表 / 详细资料四档视图，双击进查看态
- **图片管理**：一张图可以同时挂在几个类别下面，类别分上下级；分类记录存成本地库，能检查、导出、导入
- **以图搜图**：按感知哈希在本地找长相接近的图，指纹只从已有缩略图算，不打开原图
- **参考图画布**：一块置顶、背景能透的画布，图各自拖、各自缩放，也可以把剪贴板里的图或文件贴进来
- **编辑图像**：独立的编辑窗，裁剪缩放、旋转翻转、色阶、色调饱和度、颜色均衡、曝光、模糊锐化、去斑点
- **批量**：JPEG/PNG/BMP/TIFF/GIF 互转，每个格式各存一份质量设置；批量重命名；按名字搜当前文件夹或整库
- **格式**：JPG PNG BMP GIF TIFF ICO WebP HEIC PSD 与常见 RAW

作者：星雨文成。

## 构建

只在 Windows 上构建，需要 Rust（edition 2024，1.85 以上）和 Windows SDK。

```
cargo build --release --bin xsee      # 浏览窗口
cargo build --release --bin xedit     # 编辑窗口
```

产物在 `target/release/`。`build.rs` 会调 Windows SDK 自带的 `rc.exe` 把图标编进 exe；找不到 `rc.exe` 只报一条警告并跳过图标，程序照常能跑。

界面全部自绘，所以没有 Qt / 无 Electron；依赖只有 `image`、`jpeg-decoder`、`windows` 这几个 crate，见 `Cargo.toml`。

## 数据放在哪

- 分类库、格式转换设置等：exe 旁边的 `data/`（第一次建类别时才创建）
- 缩略图缓存：`%LOCALAPPDATA%\xsee\thumbs\`，可以用环境变量 `XSEE_CACHE_DIR` 指到别处

删掉这两处就等于清空所有本地记录，软件本身不带任何云端服务。

## 致谢

本项目参考了三款开源软件：

- **西西图 SEESEE**（作者 WUHAO）——浏览器形态、解码与缩略图缓存的做法
- **ImageSearch**（作者 ldqk，MIT）——以图搜图的感知哈希 + 汉明距离思路，只借思路，未接入它的代码
- **nomacs 3.22.4**（GPL-3.0）——图像编辑那批像素运算（`src/edit.rs`）按它的功能和参数口径实现

## 许可证

按 **GPL-3.0** 发布，全文见 `LICENSE`。图像编辑那部分与 GPL-3.0 的 nomacs 同源口径，所以整体沿用这一份：可以自由使用、修改、分发，但改了再分发时必须同样以 GPL-3.0 公开源码。

界面里那 47 档工具栏图标取自 36 个开源图标库（MIT / ISC / Apache-2.0 / Unlicense / CC BY 4.0），逐套的上游、版权行和硬性要求见 `THIRD-PARTY.md`，许可全文在 `LICENSES/`，每枚图标对应上游哪个图标名在 `LICENSES/glyph-names.json`。

## 已知边界

只支持 Windows；布局参考 ACDSee 3.0，除此之外不含它的任何代码和文件，不读它的数据库，也不要求机器上装过它。分类库是自己的一份 `catalog.tsv`，导入导出只认它；软件不与任何在线服务通信。
